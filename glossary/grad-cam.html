Grad-CAMGradient-weighted Class Activation Mapping，用熱圖看模型在看哪裡

用梯度找出影像中對某個類別判斷影響最大的區域，畫成熱圖。

白話解釋

深度學習模型常被說是黑盒子：它說這張有心臟肥大，但我們不知道它看的是心臟，還是影像角落的文字標記。

Grad-CAM 的想法：模型最後一層卷積的 feature map 保留了位置資訊。計算目標類別的分數對這些 feature map 的梯度，梯度大的通道代表對這個判斷比較重要。把各通道依重要性加權相加，就得到一張粗略的熱圖，紅色區域是模型「在意」的地方。

在這個研究裡

只用在 CheXpert valid 的 Cardiomegaly，比較 B0、B0+AdaBN、ConvNeXt-T 22k 三個模型在看哪裡。熱圖解析度是最後一層 feature map 的 12×12。因為熱圖疊在 CheXpert 影像上，依資料使用協議不能公開，網站上不放。

容易搞錯的地方

  • 熱圖只是「梯度大的區域」，不等於模型的判斷過程，也不保證模型真的懂醫學
  • 解析度很粗（12×12），只能看大概的區域，不能看細節
  • 只看幾張挑出來的影像容易有挑選偏差，要量化才有說服力，例如和醫師標的病灶框比重疊程度

梯度累積gradient accumulation

把好幾個小 batch 的梯度加起來再更新一次權重，在 VRAM 不夠時模擬大 batch。

白話解釋

一次丟進 GPU 的影像越多（batch 越大），需要的 VRAM 越多。384×384 的影像加上 Transformer，一張 12GB 的顯示卡可能一次只放得下 16 張。

梯度累積的做法：每次只算 16 張的梯度，但先不更新權重，把梯度加起來；累積 4 次（共 64 張）之後才更新一次。就權重更新來說，效果接近一次用 64 張。

有效 batch = 每次的小 batch × 累積次數

在這個研究裡

研究把有效 batch 固定為 64。B0 直接用 64 × 1；ResNet-50 用 32 × 2；ConvNeXt-T 和 Swin-T 用 16 × 4。硬體是 RTX 4070 Ti（12GB VRAM）。這樣不同模型的訓練條件才一致，不會因為顯示卡放不下而偷偷改變 batch 大小。

容易搞錯的地方

  • 每次的 loss 要除以累積次數，否則梯度會變成好幾倍大
  • BatchNorm 看到的仍然是每次的小 batch，梯度累積無法讓 BatchNorm 的統計量也變成大 batch
  • 訓練時間不會變短，只是讓大 batch 在小顯示卡上可行
